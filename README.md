## 🚀 Featured Projects

### 1. 🧠 [Niranthara](https://github.com/KARTHIKAKRISHNA123) — AI-Powered Mental Health Continuity Platform
> *ML-first mental health platform with cycle-aware monitoring, Tamil NLP, and real-time crisis detection*

**Tech Stack:** `Node.js` · `FastAPI` · `PyTorch LSTM` · `XGBoost` · `Firebase` · `indic-bert` · `JITAI Engine`

| Feature | Detail |
|---|---|
| 🧠 NLP Engine | Tamil + Tanglish sentiment analysis via ai4bharat/indic-bert |
| 📈 Crisis Detection | mental-roberta-base + emotion-distilroberta multi-signal fusion |
| 🔁 Personalization | Per-user LSTM cycle prediction — zero hardcoding, fully ML-driven |
| ⏰ JITAI Engine | XGBoost + SHAP for receptivity-aware intervention timing |
| 🩺 Clinician Dashboard | Real-time Firestore composite indexes, passive monitoring |
| ⌚ Wearable Integration | Google Health API + Fitbit on standalone Node.js service (port 5001) |
| 💬 Conversational AI | Gemma 4B + NVIDIA Minimax API for Tamil chat |

**Engineering Highlight:** Built a zero-hardcoding ML architecture — every threshold, cycle prediction, and intervention trigger is learned from data, not configured. JITAI receptivity modeling uses XGBoost with SHAP-explainable outputs to decide when to interrupt a user — respecting attention, not just urgency.

**Grant & Recognition:** 🏛️ Top 500 — Niral Thiruvizha 3.0 · ₹15,000 Tamil Nadu Government Pre-Seed Grant
